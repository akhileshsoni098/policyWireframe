1 Pehle Samjho: Earned vs Unearned Premium

Jab policy apni natural expiry se pehle cancel hoti hai, toh poora premium insurer ka nahi hota. Policy jitna time chali, utna premium insurer "earn" karta hai (risk cover diya). Baaki bacha hua premium insured ko return hota hai.

Earned Premium = Premium × (Days Elapsed ÷ Total Term Days) Unearned Premium = Premium − Earned Premium Return Premium = Unearned Premium (cancellation type ke hisaab se adjust)

Bas yahi concept har type me calculate hota hai — farak sirf itna hai ki insurer kitna earn karega (sirf time proportion, ya time + penalty).

2 Flat Cancellation 100% Return

Flat Cancellation kya hai

Policy kabhi effectively start hi nahi hui — yani coverage never in force. Isme insurer ko kuch bhi earned premium nahi milta, poori premium wapas.

Earned Premium = $0 Unearned Premium = Premium Return Premium = Premium (100%)
  • Kab use hota hai: binding error, duplicate policy, effective date par hi cancel, ya "flat cancel" policy.
  • Matlab: policy jese thi hi nahi — poori payment refund.
Example: $12,000 annual policy, 2nd din cancel → $12,000 return, $0 earned.

3 Pro-Rata Cancellation Time-based · App Default

Pro-Rata kya hai

Premium sirf time ke hisaab se proportionate earn hota hai. Na koi penalty, na koi benefit — jitna time policy chali, utna charge. Iska istemaal tab hota hai jab cancellation insured ki galti nahi hai (carrier / UW / non-renewal side se).

Earned = Premium × (Days Elapsed ÷ Total Days) Return = Unearned = Premium − Earned
  • Kab use hota hai: carrier ke decision se cancel, underwriting reasons, non-renewal, insured ki taraf se "fair" cancel (no claims).
  • Matlab: insured ko sirf utna charge jitna risk cover mila.
Example: $12,000 annual policy, 6 mahine (180/360 din) chali → Earned = $6,000 · Return = $6,000.

4 Short Rate Cancellation Penalty

Short Rate kya hai

Insurer pro-rata se zyada earn karta hai — insured ko thodi si penalty. Kyunki jab insured khud jaldi cancel karta hai, insurer ka acquisition cost (commission, admin, policy issue) pehle hi lag chuka hota hai. Common rule: return = unearned ka 90%.

Earned = Premium − (Unearned × 0.90) Return = Unearned × 0.90
  • Kab use hota hai: insured / broker khud cancel karwaye, premium financing, ya state rules jahan non-payment par short rate.
  • Matlab: jaldi cancel karne ki price — thoda premium insurer ke paas reh jata hai.
Example: $12,000 policy, 6 mahine chali → Unearned = $6,000 · Return = $6,000 × 90% = $5,400 (insurer ne $6,600 earn kiya).

5 Variations — Inhi se derived types

Short Rate Table

Linear 90% nahi — industry ki standard table (NAUA / ISO) use hoti hai. Pehle mahine me penalty zyada (e.g. 10% se shuru), baad me gradual kam.

Kab: jab state ya carrier table-method mandate kare.

Minimum Earned Premium

Chahe kitni bhi jaldi cancel ho, insurer fixed minimum rakhta hai (e.g. $100 ya 10% of premium). Flat/Pro-Rata ke saath combine hota hai.

Kab: chhoti policies / high acquisition cost wale LOB.

Flat / Void (Never In Force)

Flat se hi milta-julta: policy effective hone se pehle ya binding error par cancel → policy void ab initio (jaise kabhi thi hi nahi). Isme poori premium return, koi earned nahi.

7 Important: Notice Window ≠ Cancellation Type

10-Day / 30-Day / 45-Day Notice cancellation ka type nahi — ye sirf batata hai ki policy kab effective hogi (kitna notice dekar cancel hoga). Calculation type (Flat/Pro-Rata/Short Rate) alag cheez hai.

Non-Payment10-Day Notice UW / Underwriting30-Day Notice Flat / Non-Renewal45-Day Notice
Yaad rakho: Notice = "kab effective", Type = "kitna return". Dono milke cancellation complete karte hain.
