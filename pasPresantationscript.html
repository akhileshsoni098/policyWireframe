Agenda

Aaj hum kya cover karengeHar section ke end par live demo button hai — screen pe hi chalta hua dikhega.
  1. Problem — Aaj ke insurance operations ki taklifen: scattered data, koi audit trail nahi, slow notice chain, manual premium calculation aur compliance risk — aaj ka poora scenario.
  2. Solution — PAS ka concept: ek single system jo poora policy lifecycle, saare workflows aur har event ka audit trail ek jagah sambhalta hai.
  3. Architecture — MGA / Carrier model: Full, Limited aur Non-Binding binding authority — kaun kis cheez ka final decision lene layak hai.
  4. Policy Lifecycle — Poori journey ek nazar me: New Business → Issue → Active → Endorsement → Renewal → Cancellation → Reinstatement, ek timeline pe.
  5. Dashboard — Portfolio ka birds-eye view: 8 KPI cards — active policies, total premium, pending queue, notices, endorsements, cancellations, reinstatements aur waivers.
  6. New Business — Submission se issue tak: UW rules (Approve ≥5 / Refer <5 / Decline ≤3), service line, effective date, premium breakdown aur policy issue.
  7. Premium — Transparent pricing: base premium, experience modifier, schedule credit, SLA tax aur stamping — har paisa breakdown me, koi hidden charge nahi.
  8. Policy Detail — 8 tabs me sab kuch: policy info, coverage, insured, premium, transactions, timeline, documents aur endorsements.
  9. Notice Workflow — MGA → Broker → Insured: 8-step notice chain — PAS notice issue karta hai, status har step pe track hota hai, waiver ya response record hota hai.
  10. Endorsement Queue — Mid-term changes: chhote changes (typofix, address update, cancellation waiver) system me approve, bade changes manual — sab queue me visible.
  11. Cancellation Flow — Queue + MGA confirmation: received request → cancellation queue → reviewed & final decision (accept / decline / lapsed) → policy CANCELLED ya ACTIVE — har step transaction log me.
  12. Value — Aapko kya milega: single source of truth, complete audit trail, fast workflows, transparent pricing, integration-ready aur compliance-ready system.
Disclaimer: Ye ek functional wireframe / demo prototype hai — puri architecture ko isi jaisa develop kiya ja sakta hai. Aaj live demo + complete flow dekhenge.

Problem — Aaj Ka Scenario

Insurance operations me kya dikkat hoti hai

Scattered Data

Policy records alag-alag systems me — quote ek jagah, billing doosri, documents teesri. Koi single source of truth nahi.

Koi Audit Nahi

Kaunne kya change kiya, kab kiya — pata hi nahi. Regulatory compliance (SOX / NAIC) ke liye records zaroori hai.

Slow Notice Chain

Renewal / cancellation notices ka MGA → Broker → Insured tracking manual hai — status kahan hai, koi idea nahi.

Manual Premium

Premium calculation Excel / hat se — galtiyan hoti hain, transparency nahi hoti, client ko breakdown nahi dikhata.

Slow Workflows

Endorsement approval, cancellation, reinstatement — sab me manual chasing, SLA miss hota hai.

Compliance Risk

Har transaction ka trail nahi rehta — audit me fail hone ka dar, dispute me proof nahi milta.

Solution — PAS kya hai

Ek system, sab kuch

Single Source of Truth

Quote = master record. Policy ki poori journey ek hi jagah — details, coverage, premium, versions, timeline.

Complete Lifecycle

Submission → UW → Issue → Active → Notice / Endorse / Renew / Cancel / Reinstate — sab workflows built-in.

Har Event Ka Transaction

Har action ek transaction + event banata hai — correlation ID ke saath, poora trail preserve hota hai.

Notice Workflow Engine

Notices PAS → MGA → Broker → Insured jaati hain. PAS decide nahi karta — return decision record karta hai.

Integration Ready

Integration Monitor + API Log — har external service ka health aur har call ka request/response payload visible.

Browser-based

Koi installation nahi — internet wale device se kholo aur use karo. Pure frontend demo, production-ready build possible.

Design Principle: PAS "decider" nahi hai — wo system of record + workflow engine hai. Reason, decisions, confirmations sab external (MGA / Broker / Insured) se aate hain; PAS record karta hai, execute karta hai, aur har cheez audit karta hai.

Cancellation — Queue Based Flow

Reason MGA deta hai, PAS record karta hai, MGA confirm karta hai
Request ReceivedReason auto-filled (MGA)
Type Auto-AppliedPro-Rata / Short Rate
Transaction CreatedPreliminary calc
Cancellation QueueReview
Reviewed & Final CancellationACCEPT / DECLINE / Lapsed
Policy CancelledFinal recalc + txn COMPLETED

Pro-Rata

Time proportionate — carrier / UW cancel. App default.

Short Rate

Return = unearned × 90% — insured khud cancel kare.

Flat

100% return — policy never in force.

Rules: Reason field readonly hai — MGA/Broker/Billing/UW se auto aata hai, PAS decide nahi karta. DECLINE / no response par policy ACTIVE rehti hai aur transaction VOIDED. Notice raise nahi hota. Return premium = unearned premium (due balance ke saath).
